# MiniGPT – Building a GPT-Style Language Model from Scratch

## Project Overview

MiniGPT is a hands-on educational project focused on understanding the internal architecture and working principles of Generative Pre-trained Transformers (GPT).

The goal is to build a small GPT-style language model from scratch using Python and PyTorch, implementing its core components rather than relying on pretrained language models or external LLM APIs.

## Objectives

- Understand the fundamentals of Large Language Models.
- Explore how GPT models process and generate text.
- Implement tokenization and embeddings.
- Understand self-attention and multi-head attention.
- Build a decoder-only Transformer architecture.
- Train a language model using text datasets.
- Implement next-token prediction and text generation.
- Experiment with model configurations and generation strategies.
